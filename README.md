# Library Management System Using SQL

## Project Overview

The Library Management System is a database project developed using SQL to manage library operations, including book records, member information, book issues, and returns.

## Objectives

* Maintain book and member records.
* Manage book issue and return transactions.
* Retrieve library information using SQL queries.
* Generate useful reports from the database.

## Technologies Used

* SQL
* Relational Database Management System (RDBMS)

## SQL Concepts

* CREATE, INSERT, UPDATE, DELETE
* SELECT and WHERE
* GROUP BY and ORDER BY
* JOIN operations
* Aggregate functions

## Project Files

* `library_management.sql` — SQL queries used in the project.
* `screenshots/` — Screenshots showing query outputs.

## How to Use

1. Download or clone this repository.
2. Open the SQL file in a compatible database tool.
3. Execute the SQL statements in the correct order.
4. Review the query results.
